# 🎤 소리 질러 점프! (voice-jump)

목소리로 캐릭터를 점프시키는 브라우저 게임입니다. 설정한 기준보다 크게 소리를 내면 점프하고, 크게 낼수록 더 높이 뜁니다.

## 플레이 방법

1. `index.html`을 브라우저로 엽니다. (https 주소나 PC에서 직접 연 파일이어야 마이크가 동작합니다)
2. **마이크 켜고 시작**을 누르고 마이크 권한을 허용합니다.
3. 소리를 질러 장애물을 넘으세요!

- **점프 기준**: 이 값보다 소리가 커야 점프합니다.
- **마이크 감도**: 소리가 작게 잡히면 올려 주세요.
- 테스트용으로 스페이스바나 화면 탭으로도 점프할 수 있습니다.

설정과 최고 점수는 브라우저에 저장됩니다.

## GitHub Pages로 배포

저장소 Settings → Pages에서 `main` 브랜치를 선택하면 https://ksf6022-ux.github.io/voice-jump/ 에서 바로 플레이할 수 있습니다.
